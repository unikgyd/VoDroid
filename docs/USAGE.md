# 使用说明

## 安装与更新

需要 Android 13+、arm64-v8a 设备。从 [GitHub Releases](https://github.com/unikgyd/VoDroid/releases) 下载 `vodroid-<版本>.apk` 安装即可。主应用默认使用 OMAPI，Root 与模块按需配置。

已使用可选 Magisk 模块时，更新同版本的 `vodroid-magisk-<版本>.zip` 并重启。正式版后续更新应沿用相同签名；调试版与正式版签名不同，迁移前先保存需要的设置与记录。

自行编译时，可安装成品统一位于根目录 `dist/`。VoDroid APK 本身包含 LSPosed 模块；安装主应用后在 LSPosed 中启用「VoDroid」即可，Magisk 系统集成则安装同目录中的 ZIP。

## 卡片通道

默认使用 OMAPI 访问插在手机内的卡片。在「设置 → SIM 与 eSIM → 卡片通道」检测 Reader；Reader 名称、物理卡槽和当前订阅不是固定的一一对应关系，应以实际检测为准。USB CCID 适用于外接读卡器，需要授予 USB 设备权限。

「检测卡片」分别报告通道、USIM 与 eSIM 管理结果，不执行配置写入。USIM 能读出身份或完成鉴权，不代表该卡支持 eSIM 管理。OMAPI 被系统访问规则拒绝时，需使用卡片支持的授权应用或自行选择可选增强。

读取 EID 与配置列表后，可以输入 `LPA:1$...` 激活码，或打开安装链接。下载页需用户确认；配置切换、停用和删除会影响当前通信，请先断开 VoWiFi。

## 网络与运营商

应用内隧道不占 Android VPN 槽位，可以使用蜂窝数据、Wi-Fi 或其他 VPN 的线路。首页只显示本应用 SIM / ePDG / IMS 状态。点击「隧道模式」进入设置，返回后回到原页面。

自动 ePDG 发现使用当前卡身份与匹配的 Android 运营商配置。只有自动选择不适用时才填写 ePDG / P-CSCF、MNC 长度、IKE 或 AKA 策略。Legacy / Modern 的实际算法范围见 [兼容性说明](COMPATIBILITY.md)。短信发送需填写本卡的 SMSC。

SIM / eSIM 需要运营商开通 Wi-Fi Calling。能上网并不保证 UDP 500 / 4500、ePDG 或 IMS 可以访问。连接失败时在「设置 → 日志」查看停在读卡、IKE、AKA 还是 IMS 阶段。

## Root、Magisk 与 LSPosed

入口统一在「设置 → 可选增强 → Root 与模块」。进入页面不会自动申请 Root 或修改模块配置。

| 功能 | 作用与依赖 |
| --- | --- |
| 启用 Root | 启动本应用授权子进程，确认实际 UID 0；无需先装系统模块 |
| Root 卡槽 | 通过 Telephony API 对用户选择的物理卡槽 / 端口发送 APDU；不固定检测 SIM1 |
| 读卡检测 | 对所选卡槽执行只读验证，作为授权与通道可用性的检查 |
| Magisk 模块 | 将同一 APK 放入 priv-app，提供必要特权权限及 eSIM feature；安装 / 升级后重启 |
| LSPosed 应用作用域 | 对勾选的购买 / 运营商应用声明 eSIM 可用，提供先前读取的真实 EID，并转接安装请求 |
| LSPosed 电话作用域 | 部分卡片 API、系统短信桥接和实验性系统卡槽映射需要 `com.android.phone` 作用域 |
| 系统通话 | 注册独立 VoDroid Telecom 通话账户 |
| 系统短信 | 收件箱写入与幂等同步；发信桥接为实验功能 |
| 系统 eSIM 映射 | 将指定卡槽暴露为系统 eUICC，需真实 EID 与 ROM 适配，默认关闭 |

使用流程：

1. 只需 Root 读卡时，授权 Root，选择实际卡槽与端口，再执行读卡检测。
2. 需要系统权限时，通过 Magisk 安装匹配版本模块并重启。模块升级保留现有集成配置。
3. 需要应用识别及安装转接时，开启对应选项，在 LSPosed 勾选目标应用；先读取真实 EID，再「应用模块配置」并重新启动目标应用。
4. 转接到 VoDroid 的安装页后确认目标卡片和激活码。只有实际下载成功才返回成功；取消会返回错误回调。

Root 不会改变卡片内部的密钥或访问控制。可选卡片 API Hook 只针对 `io.vodroid` 的相关访问检查，不关闭系统全局签名校验。模块不关闭 SELinux。

系统映射属于实验能力。其他管理器读卡异常时，先关闭映射、应用模块配置、断开连接并重启相关应用，再单独验证 OMAPI；不要在多个管理器间同时进行配置操作。

## 日志与反馈

「设置 → 日志」支持全部 / 异常筛选、复制与分享。分享前检查 SIM 身份、服务器、电话号码及短信内容；激活码、确认码和鉴权材料不应出现在公开反馈中。参见 [反馈指南](../CONTRIBUTING.md)。
